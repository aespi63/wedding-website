# Wedding Website Template 

A responsive wedding website built from scratch with HTML, CSS, and JavaScript.
Created as both a real guest-facing site and a hands on web development project.

> **Note:** This public version uses placeholder names and event details to
> demonstrate functionality. The production version is deployed separately.

## Features

- [1 ] Home page with event overview
- [1 ] Event details (schedule, venue, directions)
- [ ] RSVP section
- [ ] Photo gallery
- [ ] Mobile-first responsive design

*(Checkboxes will be updated as features are completed.)*

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Version Control:** Git & GitHub
- **Hosting:** Vercel / GitHub Pages *(TBD)*

## Project Structure


├── index.html
├── css
├── js
└── assets


## Running Locally

1. Clone the repo:
   `git clone https://github.com/YOUR-USERNAME/wedding-website.git`
2. Open `index.html` in your browser, or use the Live Server extension in VS Code.
